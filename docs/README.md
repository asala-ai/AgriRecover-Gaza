Project Documentation

This folder contains the technical and academic documentation of the AgriRecover Gaza project.

Documentation Files

1. Project_Methodology.md – Project workflow and methodology.
2. Data_Description.md – Dataset description and spectral indices.
3. Model_Architecture.md – Artificial Neural Network architecture.
4. Model_Evaluation.md – Model performance and evaluation metrics.

Project Overview

AgriRecover Gaza uses Sentinel-2 satellite data, Google Earth Engine, and deep learning techniques to monitor agricultural vegetation and predict future NDVI values in the Gaza Strip.

All documentation describes the actual project implementation and experimental results.
