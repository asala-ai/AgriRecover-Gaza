Google Earth Engine

This folder contains the Google Earth Engine scripts used in the AgriRecover Gaza project.

Contents

- "AgriRecover_GEE.js": Satellite imagery processing and spectral index extraction using Sentinel-2.
- "Sample_Coordinates.js": Exporting the geographic coordinates of the 500 agricultural sample points.

Data Source

- Sentinel-2 Satellite Imagery
- Google Earth Engine

Spectral Indices

- NDVI
- EVI
- NDMI
- SAVI
- BSI
- NBR

Study Area

Gaza Strip, Palestine.

Study Period

January 2018 – September 2026.
