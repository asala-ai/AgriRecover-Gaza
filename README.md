# AgriRecover Gaza

### Deep Learning for Agricultural Vegetation Prediction

AgriRecover Gaza is an academic project that uses satellite data and deep learning to monitor and predict agricultural vegetation conditions in the Gaza Strip, Palestine.

## Project Objectives
- Monitor agricultural vegetation using Sentinel-2 satellite imagery.
- Analyze vegetation indices over time.
- Predict future NDVI values using an Artificial Neural Network (ANN).

## Dataset
- Study Area: Gaza Strip, Palestine.
- Source: Google Earth Engine.
- Satellite: Sentinel-2.
- Sampling Points: 500.
- Monthly Observations: 105.
- Period: January 2018 – September 2026.

## Input Features
- NDVI
- EVI
- NDMI
- SAVI
- BSI
- NBR

## Deep Learning Model
Artificial Neural Network (ANN).

Target Variable: NDVI_next_month.
